# SALES-ANALYTICS-DASHBOARD

Sales Analytics Dashboard

This project focuses on analyzing sales data and presenting key business insights through an interactive dashboard built using Microsoft Power BI.

Key Features

- Monthly Sales Trend Analysis
- Top 5 Customers by Revenue
- Sales vs. Cost by Product
- Orders Over Time
- Profit and Revenue Analysis
- KPI Cards for key performance indicators
- Date Slicer for interactive filtering

Tools Used

- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Business Intelligence

Objective

To transform raw sales data into meaningful insights, monitor business performance, identify top-performing customers and products, and support data-driven decision-making.
